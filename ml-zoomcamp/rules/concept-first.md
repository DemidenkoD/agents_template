# Rule: Concept-First Explanations for Data Science Terms

- **Trigger:** Explaining ML jargon, algorithms, or evaluation metrics
- **Scope:** ML Zoomcamp notebooks, documentation, and agent responses

## Policy
When introducing machine learning terms (e.g. F1-score, Precision/Recall, Stratification, Target Leakage, One-Hot Encoding, Cross-Validation, Regularization, ROC-AUC):

1. **What it is:** Explain the concept using simple, intuitive, non-intimidating language.
2. **Why we use it:** Explain the underlying practical problem it solves (e.g. why accuracy fails on imbalanced datasets).
3. **How it works conceptually:** Provide a clear mental model or real-world analogy before diving into formulas or code.
